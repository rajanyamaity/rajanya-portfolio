# Rajanya Maity - Frontend Developer Portfolio

A highly interactive, cyberpunk-themed portfolio built to showcase my skills, education, hackathon milestones, and software projects. 

## 🌟 Key Features

*   **Cyberpunk UI/UX:** A visually striking dark theme with neon accent colors (`#00ffcc`), a custom glowing cursor, and a dynamic "falling binary" canvas background.
*   **Terminal Boot Sequence:** An immersive startup screen that simulates a system initialization process before revealing the main portfolio.
*   **Interactive Interactions:** Features 3D tilt hover effects on project cards (for desktop) and a clean, terminal-styled modal for viewing detailed project descriptions.
*   **Bidirectional Scroll Animations:** Content smoothly reveals itself as you scroll down and hides when scrolling back up, creating a fluid browsing experience.
*   **Responsive Architecture:** Fully optimized for all screen sizes, featuring a custom hamburger menu for mobile devices and a responsive CSS Grid layout.

## 📁 Project Structure

*   `index.html`: The core semantic HTML structure, including the boot screen, navigation, hero section, timelines, project grids, and the contact terminal.
*   `style.css`: Contains all custom styling, CSS variables, keyframe animations, glassmorphism effects, and media queries for responsiveness.
*   `script.js`: Handles the interactive logic, including the custom cursor, terminal typing effect, mobile menu toggling, 3D tilt math, Intersection Observer for scroll reveals, and the binary background canvas rendering.
